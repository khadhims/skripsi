## PROSES INTERNAL OSNet — Arsitektur Matematis

### Gambaran Umum OSNet

OSNet (*Omni-Scale Network*, Zhou et al. 2019) adalah CNN ringan yang dirancang untuk ReID.
Keunggulan utama: **multi-scale feature extraction** via *Omni-Scale Residual Block (OSBlock)*.

**Alur dimensi tensor:**

```
Input Crop (87×108×3, BGR)
    │
    ▼ Pre-processing: Resize → 256×128×3 (standar ReID)
                      Normalize per channel (ImageNet mean/std)
    │
    ▼ Conv2d awal: 3→64 channel, kernel 7×7, stride=2, padding=3
    │  Output: 128×64×64  [H×W×C]
    │
    ▼ MaxPool2d: kernel 3×3, stride=2, padding=1
    │  Output: 64×32×64
    │
    ▼ OSBlock Layer1: 64→256 channel, stride=1
    │  Output: 64×32×256
    │
    ▼ OSBlock Layer2: 256→384 channel, stride=2
    │  Output: 32×16×384
    │
    ▼ OSBlock Layer3: 384→512 channel, stride=2
    │  Output: 16×8×512
    │
    ▼ Conv2d 1×1 (bottleneck): 512→512
    │  Output: 16×8×512
    │
    ▼ Global Average Pooling (GAP)
    │  Output: 1×1×512 → squeeze → vektor [512]
    │
    ▼ FC layer (Linear): 512→512 (identity/linear projection)
    │
    ▼ L2 Normalization: f ← f / ‖f‖₂
    │
    ▼ OUTPUT: vektor f ∈ ℝ^512,  ‖f‖₂ = 1.000000
```

### Struktur OSBlock (Omni-Scale Residual Block)

Satu OSBlock menggabungkan beberapa jalur konvolusi dengan kernel berbeda:

```
input x
   │
   ├─→ [Jalur 1] Depthwise Conv 3×3 → BN → ReLU
   │
   ├─→ [Jalur 2] Depthwise Conv 5×5 → BN → ReLU
   │                (atau Conv 3×3 dilated=2)
   │
   ├─→ [Jalur 3] Depthwise Conv 7×7 → BN → ReLU
   │
   └─→ [Jalur 4] Konvolusi 1×1 (pointwise, skip-like)

Semua jalur digabungkan (element-wise sum + channel attention gate):
   out = gate₁·f₁ + gate₂·f₂ + gate₃·f₃ + gate₄·f₄

Channel Attention Gate:
   g = σ(FC(GAP(f_concat)))   ← sigmoid-weighted, sum=1
```

### Matematika Konvolusi Dasar (satu layer)

Misalkan input $\mathbf{X} \in \mathbb{R}^{H \times W \times C_{in}}$,
filter $\mathbf{W} \in \mathbb{R}^{K \times K \times C_{in} \times C_{out}}$:

$$\mathbf{Y}[h, w, c_{out}] = \sum_{k_h=0}^{K-1} \sum_{k_w=0}^{K-1} \sum_{c_{in}=0}^{C_{in}-1} \mathbf{W}[k_h, k_w, c_{in}, c_{out}] \cdot \mathbf{X}[h \cdot s + k_h,\ w \cdot s + k_w,\ c_{in}]$$

di mana $s$ = stride. Diikuti Batch Normalization dan ReLU:

$$\text{BN}(y) = \gamma \frac{y - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} + \beta$$
$$\text{ReLU}(y) = \max(0, y)$$

### Global Average Pooling (GAP)

Mengkompresi seluruh peta fitur $H \times W$ menjadi satu nilai per channel:

$$f_{pool}[c] = \frac{1}{H \cdot W} \sum_{h=0}^{H-1} \sum_{w=0}^{W-1} \mathbf{Y}[h, w, c]$$

Hasil: vektor $\mathbf{f}_{pool} \in \mathbb{R}^{512}$

### L2 Normalisasi

$$\mathbf{f} = \frac{\mathbf{f}_{pool}}{\|\mathbf{f}_{pool}\|_2} = \frac{\mathbf{f}_{pool}}{\sqrt{\sum_{i=0}^{511} f_{pool,i}^2}}$$

Properti: $\|\mathbf{f}\|_2 = 1.000000$ (vektor unit pada bola satuan $S^{511}$)
